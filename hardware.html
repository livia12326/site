Componentes de Computadores e Grandezas Elétricas

1.1 Componentes Internos

1.1.1 CPU

A CPU (Unidade Central de Processamento) é o cérebro do computador, responsável pelo processamento das instruções.

1.1.2 Armazenamento

Os dispositivos de armazenamento permitem salvar e recuperar dados, como HDs e SSDs.

1.1.3 Memória

A memória RAM armazena temporariamente os dados usados pelo processador, garantindo rapidez na execução das tarefas.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte energia elétrica para alimentar os componentes internos do computador.

1.2 Componentes Externos

1.2.1 Teclado

Dispositivo de entrada usado para digitar textos e comandos.

1.2.2 Monitor de Vídeo

Dispositivo de saída responsável por exibir as imagens processadas pelo computador.

1.2.3 Mouse

Dispositivo de entrada usado para mover o cursor na tela e interagir com a interface gráfica.

1.2.4 Impressora

Dispositivo de saída que transfere informações digitais para o papel.

1.2.5 Plotter

Impressora de grande formato utilizada para impressões técnicas e gráficas.

1.2.6 Scanner

Dispositivo que converte documentos físicos em arquivos digitais.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces sem fio

Conectividade via Wi-Fi e Bluetooth para comunicação entre dispositivos.

1.3.2 Áudio

Conectores de áudio permitem a transmissão de som para fones, microfones e caixas de som.

1.3.3 Rede (Ethernet)

Portas Ethernet são utilizadas para conexões com a internet via cabo.

2. Grandezas Elétricas

2.1 Potência Elétrica

A potência elétrica mede a quantidade de energia consumida ou fornecida por um componente elétrico.

2.2 Tensão Elétrica

A tensão elétrica, medida em volts, representa a diferença de potencial elétrico entre dois pontos.

2.3 Corrente Elétrica

Corrente elétrica é o fluxo de elétrons através de um condutor, medido em amperes.
